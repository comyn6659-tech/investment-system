## 3. 财务数据

### 3.1 来源与接口

| 项 | 内容 |
|---|---|
| 来源 | 东方财富数据中心（F10 合并报表） |
| 接口 | `RPT_F10_FINANCE_GBALANCE`（资产负债表）、`RPT_F10_FINANCE_GINCOME`（利润表）、`RPT_F10_FINANCE_GCASHFLOW`（现金流量表） |
| 取数方式 | 按报告期一次取全市场，每页 500 行，按 `SECURITY_CODE` 区间分 SZ/SH 两次请求；客户端再按 `.SZ/.SH` 过滤 |
| 起止 | 资产负债表 2015–2025；利润表、现金流量表 2016–2025 |
| 频率 | 年报（`REPORT_DATE=YYYY-12-31`） |
| 单位 | 元；合并口径 |
| 字段 | 归母净资产、归母净利润、营业总收入、利润总额、利息费用/财务费用、经营现金流净额、资本开支、折旧、摊销、有息负债分项、货币资金 |
| 覆盖 | 评价范围 3,252 家，财务完整 3,234 家，**99.45%** |

2015 年资产负债表只用于计算 2016 年 ROE 的平均归母净资产（期初数），不进入 10 年评价窗口。

### 3.2 逐年覆盖率

| 报告期 | 应有公司 | 财务完整 | 覆盖率 |
|---|---:|---:|---:|
| 2016 | 2,562 | 2,561 | 99.96% |
| 2017 | 2,977 | 2,975 | 99.93% |
| 2018 | 3,069 | 3,064 | 99.84% |
| 2019 | 3,252 | 3,248 | 99.88% |
| 2020 | 3,636 | 3,633 | 99.92% |
| 2021 | 4,107 | 4,106 | 99.98% |
| 2022 | 4,442 | 4,441 | 99.98% |
| 2023 | 4,677 | 4,677 | 100.00% |
| 2024 | 4,754 | 4,753 | 99.98% |
| 2025 | 4,844 | 4,842 | 99.96% |

“应有公司”按上市年份确定；“财务完整”要求该年归母净资产、归母净利润、经营现金流净额、资本开支均有值。
不完整的 18 家是实际缺年报/缺核心字段（例如北京文化 2021、2024），不是接口整年缺失；
这些公司按“窗口内缺年报 = 该条不通过”处理，不进入入池名单。

### 3.3 存储格式

按 2026-11-12 补充要求，全市场数据不采用“一只股票一个 JSON”的格式，而是：

- `balance-2015.csv.gz` … `balance-2025.csv.gz`；
- `income-2016.csv.gz` … `income-2025.csv.gz`；
- `cashflow-2016.csv.gz` … `cashflow-2025.csv.gz`；
- 每张表旁的 `*.meta.json` 统一记录来源、接口、URL、报告期、列、行数、内容哈希；
- 固定快照清单汇总每张表的哈希，得到 `snapshot_id`。

## 4. 治理类数据逐项核查

### 4.1 审计意见（不可得，未检验）

| 尝试 | 结果 |
|---|---|
| akshare 1.20.35 | 没有审计意见函数 |
| 东方财富 `RPT_AUDIT_OPINION`、`RPT_AUDIT_OPINION_DETAIL`、`RPT_F10_FINANCE_AUDIT` | 均返回“报表配置不存在” |
| 巨潮资讯公告接口 | 只有公告标题与 PDF 链接，不含逐家公司逐年“审计意见类型”结构化字段 |
| 用报表字段推断 | 无依据，不做 |

**处理**：该条件记“本版未检验”，报告首页列出；不从报表数据推断“标准无保留”。

### 4.2 处罚、立案、公开谴责（不可得，未检验）

| 尝试 | 结果 |
|---|---|
| 东方财富 `RPT_VIOLATION`、`RPT_PUNISHMENT`、`RPT_INVESTIGATION` 等 | 均返回“报表配置不存在” |
| 证监会行政处罚 JSON feed | 只覆盖近期，且不含交易所公开谴责；无法覆盖最近 5 年全市场 |
| 第三方违规处理数据库 | 不采用拼接数据 |

**处理**：该条件记“本版未检验”。

### 4.3 控股股东质押比例（不可得，未检验）

| 尝试 | 结果 |
|---|---|
| 东方财富 `RPT_CSDC_LIST` | 有**公司整体**质押比例（质押股数 ÷ 总股本），最新 2026-11-06，2,246 家 |
| 东方财富 `RPTA_APP_ACCUMDETAILS` | 单笔质押明细，不是“控股股东最新质押余额” |
| 全市场批量字段 | 没有“控股股东质押股份 ÷ 其所持股份” |

**处理**：公司整体质押比例只作为旁证存入快照，**不参与规则**；
“控股股东最新质押比例”条件记“本版未检验”，不拿公司整体比例替代。

### 4.4 现金分红（可得）

| 项 | 内容 |
|---|---|
| 来源 | 东方财富 `RPT_SHAREBONUS_DET`（分红送配） |
| 接口 | 按报告期分页取全市场 |
| 起止 | 2021-06-30、2021-12-31 … 2025-06-30、2025-12-31，共 10 个报告期 |
| 覆盖 | 19,014 行，4,417 家公司至少有一个现金分红方案 |
| 口径 | 每 10 股派现（含税）÷ 10 × 总股本；按财年归集中期与年度方案；取消/终止方案不计 |
| 无方案公司 | 记为 0（没有分红方案），不记缺失 |

## 5. 缺数据规则如何执行

| 情形 | 处理 |
|---|---|
| 某条件全市场都取不到 | 记“本版未检验”，池子照常发布，首页写明；本版为审计意见、处罚/立案、控股股东质押 3 条 |
| 某条件只对个别公司缺数据 | 该公司“待定（缺 X）”，不入池；不用默认值、行业均值或推断填补 |
| 窗口内应有年报而缺失 | 该条不通过；不用相邻年份或季度数据补 |
| 未检验 vs 通过 | 未检验不等于通过；入池公司成绩单保留 `—` 标记，报告明确列出 |
