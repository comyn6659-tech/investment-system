## 1. A. 政策实现（L1）

### 1.1 政策文件

`data/policies/equity-policy-v1-draft.json`（`schema_version = equity-policy/1`，
`policy_id = equity-policy-v1-draft`，`status = draft_unapproved`，`approved = false`）。

| 区块 | 内容 |
|---|---|
| `discount_rate` | 规范化无风险利率、股权风险溢价（5.14%）、公司特定溢价（0）、债务成本下限、市值权重、WACC |
| `forecast` | 5 年预测期、第 1 年已披露增速、第 2–5 年 min(5 年复合增速, 10%)、3 年平均报表比率、派息率路径 |
| `terminal` | g 基准 2.0%、上限 min(2.5%, 无风险利率)、g ≤ ROE×留存率、再投资率 = g/新投资回报率 |
| `scenarios` | 悲观（增速 −2pp、g 1.5%）、基准、乐观（增速 +2pp、ROI = 近 5 年平均 ROE、g 2.5%）；折现率不随情景变 |
| `quality` | P6 选择阈值、P7 交叉检查、P8 勾稽 15%、P9 措辞带宽、股本/现金/少数股东/金融子公司口径、近似影响 |
| `grade` | A/B/C 全部条件、安全边际 25%/40%、银行最高 B、未实现族不结论、安全边际敏感性网格 |
| `conclusion` | 候选买点 / 回避 / 等待 / 无法判断的机械映射 |
| `sensitivity` | 折现率 ±0.5pp、终值增长 ±0.5pp、安全边际 20/25/30% 与 35/40/45% |

每个参数节点都带 `basis`（理由）或 `source`（来源）。`engine/policy/equity.py` 的
`validate()` 会遍历整棵参数树，缺依据即拒绝加载。

### 1.2 代码不散落数字

- 业务判断只通过 `policy.value(...)` / `policy.node(...)` 取数；模块内只保留 0/1 等结构常量；
- 测试 `test_policy_module_has_no_hardcoded_policy_numbers` 扫描四个模块的源码，
  禁止出现 `0.0514`、`0.40`、`0.25`、`0.015`、`0.025`、`0.8`、`0.6` 等政策值；
- 测试 `test_changing_policy_changes_behavior` 把 A 级安全边际改成 30%，同级结果立刻变成 30%，
  证明行为来自政策文件而不是代码常量。

### 1.3 政策未规定、由实现方机械补齐的输入

政策只写死了「用什么规则」，没有逐项规定报表比率的预测来源。实现方按
`mechanical_implementation.rules` 统一补齐，并随报告披露：

| 输入 | 机械规则 |
|---|---|
| EBIT 利润率、折旧摊销/收入、资本开支/收入、营运资本强度、实际税率 | 最近 3 个财年算术平均 |
| 实际税率上下限 | 0 ～ 25%（法定税率） |
| 第 1 年增速 | 最近一期累计营收同比（2026 三季报 vs 2025 三季报）；取不到退回受 10% 上限约束的 5 年复合增速 |
| 有息负债科目未列示 | 按 0 处理，并在数据说明中列出科目名 |
| 库存股 | 数据源未单列，按 0 处理 |
| 受限资金 | 货币资金 − 期末现金及现金等价物（两个口径取较小值），计为近似项 |
| 少数股东权益 | 账面值；损益占比 > 15% 时按相同市盈率定价与账面值差额计近似影响 |
| 金融子公司 | 发放贷款+吸收存款 > 总资产 5% 时，按 FCFF 勾稽差额相对值传导计近似影响 |
| 乐观情景 ROI ≤ g | 再投资率会超过 100%，退回股权成本并记录退化 |

这些规则全部登记在政策文件 `mechanical_implementation` 中，不属于阈值调整。

## 2. A. 折现率、终值与情景（L2）

### 2.1 折现率

| 项目 | 取值 | 说明 |
|---|---|---|
| 10 年期国债最新值 | 1.6039%（2026-11-11） | `data/policy-trial/macro/cn-10y-yield.json` |
| 近 10 年月末均值 | 2.7629%（2016-11-30 → 2026-10-30，120 个月） | 同上 |
| 规范化无风险利率 | **2.7629%** | 取两者较高者（均值） |
| 股权风险溢价 | 5.14% | Damodaran 中国总股权风险溢价（2026-01） |
| 公司特定溢价 | 0% | 政策取消 |
| 股权成本 | **7.9029%** | 无风险利率 + 股权风险溢价 |

FCFF 用 WACC：权重 = 权益市值 /（权益市值 + 账面有息负债），债务成本 =
利息费用 / 平均有息负债，下限为规范化无风险利率，税后计入。股息路线用股权成本。
手算测试见 `test_discount_rate_build_matches_hand_calculation`、
`test_cost_of_debt_floors_at_risk_free`。

### 2.2 终值与再投资一致性

```
g = min(情景 g, min(2.5%, 规范化无风险利率), ROE_最新财年 × (1 − 3 年平均派息率))
再投资率 = g / 新投资回报率
终值现金流 = 末期 NOPAT（或 EPS）× (1+g) × (1 − g/新投资回报率)
终值 = 终值现金流 / (折现率 − g)，再折现 N 期
```

基准与悲观情景的新投资回报率 = 股权成本；乐观情景 = 近 5 年平均 ROE。
**经济含义**：当新投资回报率 = 股权成本时，终值化简为「末期 NOPAT ÷ 股权成本」，
增长在公式中相互抵消（价值中性增长），这是政策「新投资不产生超额回报」的机械结果。
手算测试：`test_fcff_value_matches_hand_calculation`、
`test_dividend_value_matches_hand_calculation`、
`test_terminal_payout_equals_one_minus_g_over_roi`。

### 2.3 情景

三档情景共用同一折现率，只改增速与终值参数：

| 情景 | 增速 | 终值 g | 新投资回报率 |
|---|---|---|---|
| 悲观 | 基准各年 −2pp | 1.5% | 股权成本 |
| 基准 | 第 1 年已披露、第 2–5 年 min(5 年 CAGR, 10%) | 2.0% | 股权成本 |
| 乐观 | 基准各年 +2pp | 2.5%（受上限约束） | 近 5 年平均 ROE |

手算测试：`test_growth_paths_use_disclosed_year_one_and_capped_cagr`、
`test_terminal_growth_is_capped_by_roe_and_retention`、
`test_terminal_growth_is_capped_by_risk_free`、
`test_optimistic_scenario_uses_five_year_average_roe`。

### 2.4 600519 两模型分歧

新规则下 600519：FCFF 基准 **1,227.36 元/股**，股息折现 **1,087.25 元/股**，
分歧 **−11.42%**（第二阶段约 24%）。分歧缩小的原因：终值再投资一致性规则同时约束两条路线的
终值派息率，消除了「终值增长与留存率不一致」这一主要来源；剩余差异来自 FCFF 与
「EPS × 派息率」对可分配现金的定义不同（留存现金在股息路线里没有被计价），不是需要取平均的误差。
详见试运行报告 §6，测试 `test_maotai_two_model_divergence_under_new_rules`。

## 3. A. 确定性等级与结论映射（L3）

### 3.1 等级

| 等级 | 条件（全部满足） | 安全边际 |
|---|---|---|
| A | 可得 ≥7 个财年且 10 年内无亏损；近 5 年 OCF/归母净利润 ≥ 0.8；净负债/EBITDA < 2；交叉检查分歧 < 25%；近似项影响 < 每股价值 2% | 25% |
| B | 最近 7 年至多 1 年亏损；OCF/利润 ≥ 0.6；净负债/EBITDA < 3；分歧 < 40%；近似项影响 < 5% | 40% |
| C | 其余（含交叉检查不可用、近似项无法量化、银行缺风险证据） | 不给正式结论 |

净负债 = 有息负债 − 可抵扣现金；EBITDA = EBIT + 折旧摊销。
银行只有取得资本充足率、不良率、拨备覆盖率并通过第二阶段检查时最高 B 级，否则 C。
保险、券商、明显周期、困境、控股沿用「路线不支持」，不给正式结论。

边界测试：`test_grade_a_when_all_conditions_pass`、`test_grade_b_uses_seven_year_loss_window`、
`test_grade_boundary_net_debt_to_ebitda`、`test_grade_c_when_cross_check_unavailable`、
`test_grade_c_when_approximation_cannot_be_quantified`、
`test_bank_without_risk_evidence_cannot_exceed_c`。

### 3.2 结论映射

```
候选买点：A/B 且 complete 且 P ≤ V_基准 × (1−M) 且 P ≤ V_悲观
回避：    A/B 且 complete 且 P > V_乐观
等待：    A/B 且 complete 的其余情形
无法判断：C 级、partial、资料不足、路线不支持、引擎错误
```

不对模型取平均或取高；主模型决定结论，交叉检查只影响等级。
测试覆盖「恰好等于门槛」「低于基准门槛但高于悲观价值」「恰好等于乐观价值」等边界
（`test_conclusion_boundaries`、`test_conclusion_requires_pessimistic_condition`），
以及 C 级/partial/insufficient/unsupported 一律无法判断
（`test_grade_c_and_partial_are_always_undetermined`）。

## 6. B. 只追加信号账本（L6）

`data/ledger/candidate-a-signals.jsonl`：

- 首次建立账本时只写入「最新一个已结束自然周」的观察点（3 条：2026-W45 / 2026-11-06），
  不回溯全部历史；
- 同一标的同一周重复运行内容一致 → 跳过；内容不一致 → 报冲突并退出，不覆盖；
- `record_id` 是内容哈希（不含追加时刻），历史被改写会被 `--check` 发现；
- 只记录已结束自然周的观察点，未结束的周不写入，避免把盘中临时值固化。

命令：

```bash
.venv/bin/python tools/update_signal_ledger.py            # 追加
.venv/bin/python tools/update_signal_ledger.py --dry-run  # 预览
.venv/bin/python tools/update_signal_ledger.py --check    # 完整性
```

## 8. 发现与未解决项（提请设计方确认）

1. **终值派息率与「不假设派息率上升」存在公式层面的张力**：终值派息率 = 1 − g/新投资回报率，
   可能高于近 3 年历史派息率（例如 600309：历史 30.5%、终值隐含 74.7%）。由于基准情景
   新投资回报率 = 股权成本，终值会化简为「末期 NOPAT ÷ 股权成本」，该派息率变化不改变基准价值；
   但在乐观情景（ROI = 5 年平均 ROE）下会影响结果。试运行按再投资一致性等式执行并逐只披露，
   若设计方希望以「不上升」为准，需要改写终值公式。
2. **受限资金的代理口径偏保守**：用「货币资金 − 期末现金等价物」估算，会把三个月以上定期存款
   一并当作受限资金（例如 600519：估算 432 亿元，约占基准价值 2.8%，使其从 A 降为 B）。
   若获得年报附注的受限资金明细，应改用披露值。
3. **交叉检查不可用时按 C 处理**：政策未规定第二路线拒绝计算时如何定级，试运行按
   「无法验证分歧 → 不能给 A/B → C」处理。若设计方希望允许单模型定级，需要明确规则。
4. **银行路线仍缺资本与资产质量证据**：本次两只银行（600036、601398）均因缺核心一级资本充足率、
   不良率、拨备覆盖率与监管下限而停在资料不足，按政策为 C 级。免费接口的缺口在第二阶段已记录。
5. **机械补齐的报表比率**：政策未规定 EBIT 利润率、资本开支、折旧摊销、营运资本与税率的预测来源，
   试运行采用最近 3 年算术平均；若设计方有更明确的口径，需要写进政策。
6. **数据源回退**：东方财富 push2 行情与个股信息接口在本环境下被限流，价格改用新浪不复权日线、
   公司资料改用巨潮股本变动与行业分类；每只快照都在 `coverage` 中记录了实际来源，未用其他数据凑。
