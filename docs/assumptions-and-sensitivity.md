# 研究假设、参数来源与敏感性

版本：`assumption-set/1`｜生成日期：2026-11-11｜对应代码 `phase2-0.2.0`

本文件交代本轮**研究参数候选**的来源、推导与敏感性。所有参数都是候选，
**没有任何一项获得正式使用批准**；代码里也不存在把它们升级为 `validated` 的路径
（`engine/assumptions/schema.py::ALLOWED_STATUSES` 只允许 `research_pending_approval` / `draft`）。

---

## 1. 三类参数必须分开

| 类别 | 含义 | 本轮来源 |
|---|---|---|
| `observed_data` | 直接来自报表或公开数据 | 实际税率、派息率、ROE、折旧摊销占比、资本开支占比、无风险利率 |
| `derivation` | 由观测值按明确公式推出 | 基期 EBIT 利润率、FCFF/归母净利润、WACC 构建、2026 年增速起点 |
| `research_hypothesis` | 本轮提出的研究假设，没有可直接观测的来源 | 股权风险溢价、公司特定溢价、终值增长、营运资本增量比例、情景路径 |
| `policy_pending_approval` | 需要设计方决定的使用政策 | 见第 6 节；本轮没有把任何候选参数写成政策 |

**没有不带来源的参数**：`AssumptionSet.validate` 要求每个驱动项都在 `provenance` 里，
且 `source` 非空，否则假设文件直接加载失败。

## 4. 情景定义

情景由输入假设定义，不是按估值高低挑出来的。全部年份都显式给出，不使用「继承基期」的隐式默认。

| 情景 | 600519 FCFF | 600900 股息 |
|---|---|---|
| bear | 收入停滞（0/2/2/2/2%）、EBIT 利润率回落至 60%、资本开支 2.5%、`g=1.5%` | 每股收益 −10% 后零增长、派息率 70%、`g=1.5%` |
| base | 见 §3.1 | 见 §3.3 |
| bull | 收入 3/5/5/4.5/4%、EBIT 利润率 67%、资本开支 1.8%、`g=2.5%` | 每股收益 −3% 后 5/5/4/3%、派息率 72%、`g=2.5%` |

`scenario_range_not_confidence_interval`：它**不是**统计置信区间。

## 5. 敏感性（真实运行结果）

单变量变动，其他假设保持不变。完整表见 `docs/phase2-samples.md`。

### 5.1 600519 FCFF（基准 1,341.13 元/股）

| 变量 | 变动 | 估值（元/股） | 相对基准 |
|---|---|---|---|
| 收入增速 | +1.0pp | 1,395.64 | +4.1% |
| 收入增速 | −1.0pp | 1,288.46 | −3.9% |
| EBIT 利润率 | +1.0pp | 1,361.54 | +1.5% |
| 资本开支/收入 | +0.5pp | 1,327.40 | −1.0% |
| **折现率** | **+0.5pp** | **1,229.78** | **−8.3%** |
| **折现率** | **−0.5pp** | **1,475.22** | **+10.0%** |
| **终值增长** | **+0.5pp** | **1,450.27** | **+8.1%** |
| 终值增长 | −0.5pp | 1,250.49 | −6.8% |

### 5.2 600900 股息（基准 20.97 元/股）

| 变量 | 变动 | 估值（元/股） | 相对基准 |
|---|---|---|---|
| 每股收益增速 | +1.0pp | 21.94 | +4.7% |
| 派息率 | +3.0pp | 21.85 | +4.2% |
| **股权成本** | **+0.5pp** | **18.91** | **−9.8%** |
| **股权成本** | **−0.5pp** | **23.53** | **+12.2%** |
| **终值增长** | **+0.5pp** | **23.12** | **+10.3%** |
| 终值增长 | −0.5pp | 19.24 | −8.2% |

**读法**：两个样本的价值都由「折现率 + 终值增长」主导（合计解释 ±10% 量级），
经营假设（收入/利润率/派息率）的影响小一个数量级。终值现值占总价值 75–82%，
这意味着结论对长期假设高度敏感；这也是本轮不把它们称为「估值结论」的原因之一。

## 6. 需要设计方判断的政策事项

以下事项本轮**只做研究候选**，没有变成政策；请设计方在复验时决定是否批准、以及批准成什么数值。

| # | 事项 | 本轮取值 | 为什么需要设计方决定 |
|---|---|---|---|
| P1 | 股权风险溢价（A 股） | 5.0%（大市值）、4.6%（公用事业） | 直接决定估值水平；不同取值会把「研究价值」推过或推不过现价 |
| P2 | 公司特定溢价 | +0.8pp / +0.4pp | 属于主观判断，需要统一口径，否则不同标的之间不可比 |
| P3 | 终值增长 | 2.0%（区间 1.5–2.5%） | 终值占价值 75–82%，是最敏感的参数 |
| P4 | 预测期长度 | 5 年 | 更长会降低终值占比但增加假设数量 |
| P5 | 派息率路径 | 维持最近财年水平 | 是否允许假设派息率变化，属于政策 |
| P6 | 模型适用性阈值 | 资本开支/收入 10%、FCFF/净利润 0.70、派息率 55%、周期波动 8%/回撤 15% | 决定同一公司走哪条路线；本轮是研究起点 |
| P7 | 交叉检查分歧容忍度 | 25% | 超过即标 `CROSS_CHECK_DIVERGENCE`；本轮 600519 恰好 24.3%，接近阈值 |
| P8 | FCFF/OCF 勾稽容差 | 15% | 决定结果是 `complete` 还是 `partial` |
| P9 | 现价比较的「大致相当」带宽 | ±5% | 只影响措辞，不影响数字 |
| P10 | 银行资本与拨备下限 | **未设定** | 必须来自监管文件并写入假设文件；代码不含默认值 |
| P11 | 银行 RWA 增速 `rwa_growth` | **未设定** | 决定资本一致性派息上限 |
| P12 | 股本口径 | 当前总股本 | 是否改用加权股数、如何处理回购注销，属于政策 |

## 7. 600519 交叉检查为什么差 24.3%

主模型 FCFF 1,341.13 元/股，股息折现 1,015.59 元/股，差 −24.3%。差异不是算错，而是口径不同：

- 两条路线用同一个折现率（7.40%）与同一份财务事实，但终值增长都设为 2%，
  而 600519 的可持续增长（ROE 33.65% × 留存率 21.1%）约 7.1%。
- **股息折现的永续项只给已分配部分 2% 的增长**，留存收益再投资创造的价值没有进入终值；
  FCFF 把全部自由现金流（含留存部分）按 2% 永续折现，因此更高。
- 结论：这个差额本身是「终值增长假设与可持续增长不一致」的信号，而不是取平均的理由。
  结果里不平均、不择优，只并列展示并标记差异（本轮 24.3% < 25% 阈值，未触发 `CROSS_CHECK_DIVERGENCE`）。

## 8. 参数变更流程

1. 修改 `data/assumptions/*.json` 里的数值与来源说明；
2. 文件内容哈希改变 → `assumption_id` 改变 → 结果里的 `assumptions` 与 `research_valuation.assumption_id` 随之变化；
3. 重跑 CLI 得到新结果；旧结果的 `analysis_id` 不变（它由状态与原因码决定），
   但 `assumption_id` 会明确指向当时用的是哪一版假设；
4. 不允许「改数字但保持 assumption_id」——声明 id 与内容哈希不一致会直接加载失败。

**反向操作被禁止**：不能为了得到更低的估值去调高折现率、压低收入增速或正常化现金流；
本轮所有参数都先写来源与推导，再看结果。
