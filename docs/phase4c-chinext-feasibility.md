# 创业板指（399006）数据可行性报告

生成时间：2026-11-12｜生成脚本：`tools/build_chinext_data.py`｜机器可读记录：[data/coverage/chinext-feasibility.json](../data/coverage/chinext-feasibility.json)

本报告只回答一件事：**创业板指有哪些官方数据、这些数据能支持做到哪一步**。
结论按施工单 §1 的三档判定，不为了让策略跑通而使用第三方估值、板块 PE 或拼接序列。

## 1. 结论

| 项目 | 结论 |
|---|---|
| 官方日收盘 | **可得**，2010-06-01 至 2026-11-11，3,993 个交易日 |
| 官方全收益（399606） | **可得**，同区间、同观测数 |
| 官方日度/月度市盈率历史 | **不可得**；官网只有最新一个交易日的 PE/PB 快照 |
| 跟踪 ETF 159915 产品资料 | 可得（价格、净值、费率、跟踪标的），与既有 ETF 同口径 |
| 本批判定 | **`short_history_only`**：接入收盘、全收益、官方当前估值快照、指数快照与 ETF 资料；**不做** 5 年分位、周度候选 A 信号、研究回测、候选 A 账本记录 |

官方当前快照（2026-11-11）：PE 滚动 **25.1325**、PE 静态 31.6183、PB **4.07**。
这只是一个交易日的值，能说明“此刻官方口径是多少”，不能说明历史位置。

## 2. 四项数据逐项核查

### 2.1 创业板指官方日收盘

| 项 | 内容 |
|---|---|
| 来源 | 深圳证券信息有限公司（国证指数） |
| 接口 | 国证指数官方历史行情接口 `hq.cnindex.com.cn/market/market/getIndexDailyDataWithDataFormat` |
| 字段 | `timestamp`、`close`（另含 open/high/low/volume/amount） |
| 起止 | 2010-06-01 至 2026-11-11 |
| 频率 | 日频 |
| 观测数 | 3,993（接口原始 3,994 行，含基日 2010-05-31 的 1000 点基点行；按发布日截断，丢弃 1 行） |
| 是否官方 | 是 |
| 是否采用 | 是；`cnindex.official_history` / `official_close` |

接口不提供公布时刻与修订版本；序列按内容哈希保存，无法在 ID 不变的情况下改写观测。

### 2.2 官方估值：只有当前快照，没有历史

| 尝试 | 结果 |
|---|---|
| 国证指数官网指数列表 | 有 `peStatic`、`peDynamic`、`pb`，但只有**最新交易日**；日期参数（`date`、`tradeDate`、`searchDate`、`checkDate`、`indexDate`、`queryDate`）实测均被忽略 |
| 国证指数官方历史行情 | 只有 OHLC/成交，无 PE/PB 字段 |
| 国证指数指数详情页 | 只有指数简介、样本、相关产品；没有估值历史下载 |
| 国证指数“行业市盈率”页 | 对象是行业，不是指数；下载的是行业 PE 表 |
| 深交所指数行情报表（1826_snapshot） | 字段只有前收/开/高/低/收/涨跌幅/成交额，没有市盈率 |
| 深交所指数列表（1812_zs） | 只有代码、名称、基日、基日指数、起始计算日 |
| 深交所“创业板”板块行业统计（1804，tab4） | 有 19 个行业的**加权平均市盈率**，对象是板块/行业，不是创业板指 100 只样本 |
| CEIC“深交所 : 创业板 : 市盈率和市净率 : 日度” | 第三方转载，标注来源深交所；最新约 35.39 倍，是创业板**板块**口径，与创业板指 25.13 倍不是同一对象 |

因此：**官方日度或月度历史估值没有取得**。没有把以下任何一项拿来凑分位：

- CEIC/理杏仁/同花顺等第三方估值；
- 创业板板块 PE（35.39）或行业加权 PE；
- 用成分股财务数据自行合成的“指数 PE”；
- 用当前单日值外推或插值出的历史。

## 3. 据此做了什么、没做什么

### 3.1 已做

1. **序列库**：399006 官方收盘、399606 官方全收益，固定序列、内容哈希、起止与观测数进入“序列库覆盖”。
2. **官方当前估值快照**：PE 滚动、PB 各 1 个观测，进入指数画像的“官方短历史（并列事实）”，不参与长历史排名。
3. **指数快照**：官方收盘 + 官方当前 PE/PB；覆盖块明确写 `valuation_history.available=false`、`supports_5y_window=false`。
4. **名称识别**：“创业板指”“创业板指数”“399006”识别为 `INDEX:399006.SZ`；单独“创业板”按板块歧义澄清；“创业板50”等创业板指数变体为范围外。
5. **ETF 159915**：纳入既有 ETF 产品资料检查（价格、净值、费率、跟踪标的、折溢价缺口），不做执行检查。
6. **报告说明**：创业板指成分股更替大，历史估值分位的可比性弱于沪深300；即使将来取得官方历史，分位也只与自身历史比较。

### 3.2 未做及原因

| 未做 | 原因 |
|---|---|
| 5 年月度估值画像 | 没有官方月度历史序列；不能用第三方或板块 PE 代替 |
| 候选 A 周度研究信号 | 规则需要官方 PE 日频历史；只有 1 个交易日，无法形成 5 年周度池 |
| 候选 A 研究回测 | 同上；不拿价格指数或板块 PE 冒充 |
| 候选 A 信号账本 399006 记录 | 没有信号可写；账本保持 3 条既有记录不变 |

## 4. 为什么不能拿板块 PE 凑

CEIC 页面把“深交所 : 创业板 : 市盈率和市净率 : 日度”标注为深交所来源，最新约 35.39 倍；
国证指数官网同日创业板指 PE 滚动为 25.13 倍。差异来自样本与加权方式：

- 创业板指是 100 只样本股、按自由流通市值加权的指数；
- “创业板”板块 PE 覆盖全部创业板股票，且第三方转载的加权方式未说明；
- 两者不是同一对象，拼在一起会把“板块估值”误写成“指数估值”。

同理，深交所行业统计里的“加权平均市盈率”是行业口径，不是指数口径；本批只把它登记为
“存在但未采用”的官方数据。

## 6. 限制

- 本结论只针对本次已测的官方接口与参数；不代表所有官方渠道（含付费/授权渠道）都没有历史估值。
- 官方当前 PE/PB 的加权方式、亏损样本处理未在页面说明，记为 `unknown`。
- 单日快照的“可获得时间”未知；不用于盘中历史判断。
- 没有为了让分位、信号或回测通过而改变候选 A 阈值、股票池或数据口径。
