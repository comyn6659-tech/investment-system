## 2. 个股政策 v1.1（决策②，已批准 2026-11-12）

### 2.1 覆盖范围与路线

- 覆盖全部沪深 A 股；不覆盖保险、券商、强周期、困境公司、控股平台（这些沿用「路线不支持」，
  结论为无法判断），银行走银行专用估值。
- 两种估值路线：**FCFF（企业自由现金流折现）** 与 **股息折现（DDM）**；由公司特征机械分流，
  另一条只作交叉检查，**不对多模型取平均、不取高**。
- 正式结论只给 A/B 级且 `complete` 的结果；C 级、partial、资料不足、路线不支持、引擎错误一律
  「无法判断」，研究数字只作参考。

### 2.2 折现率

| 项 | 规则 |
|---|---|
| 规范化无风险利率 | max（最新 10 年期国债收益率，近 120 个月月末 10 年期国债收益率均值）；当前 2.7629% |
| 股权风险溢价（ERP） | Damodaran 中国总股权风险溢价，当前 5.14%（2026-01 版），每半年更新 |
| 公司特定溢价 | 0（不逐家主观加点） |
| 股权成本 | 无风险利率 + ERP + 0；当前 7.9029% |
| 债务成本 | 实际利息费用 ÷ 平均有息负债，不低于规范化无风险利率；债务权重 < 1% 时显示「不适用（债务可忽略）」 |
| 资本权重 | 权益 = 现价 × 总股本；债务 = max(0, 账面有息负债 − 可抵扣现金)；净现金公司 WACC = 股权成本 |
| WACC | E/(D_net+E) × 股权成本 + D_net/(D_net+E) × 债务成本 × (1 − 实际税率)；FCFF 用 WACC，股息路线用股权成本 |

折现率是政策，不是情景变量：三档情景用同一折现率。

### 2.3 预测、终值与三情景

- 预测期 5 年；第 1 年增速取「最近一期累计营收同比」并封顶 10%，取不到时退回封顶后的 5 年复合增速。
- 稳态增速 = min（10%，5 年复合增速，3 年复合增速）；第 2–5 年线性过渡到稳态。
- 终值增长：基准 2.0%，上限 min(2.5%, 规范化无风险利率)，且 g ≤ 最新财年 ROE ×（1 − 3 年平均派息率）。
- 终值新投资回报率：FCFF 基准/悲观取 WACC，乐观取近 5 年平均 ROE；股息路线取股权成本。
- 情景：
  - **基准**：上述规则，终值增长 2.0%。
  - **悲观**：各年增速 −2pp，终值增长 1.5%，EBIT 利润率取近 5 财年最低（FCFF）或 EPS 按近 5 年
    最低净利率打折（股息），折现率同基准。
  - **乐观**：各年增速 +2pp，终值增长 2.5%（受上限约束），新投资回报率取近 5 年平均 ROE，
    折现率同基准。
- 护栏（触发即 partial / 等级 C / 无法判断）：
  - 终值连续性：主模型是默认兜底、基准情景显式期 FCFF 合计 ≤ 0、基准情景终值占比 ≥ 90%。
  - 悲观价值 ≤ 0。
  - 杠杆护栏：净有息负债 ÷（净有息负债 + 权益市值）> 50%。
  - 基期异常：基期营收同比绝对值 > 40% 或归母净利润同比绝对值 > 60%。
  - 现金流勾稽差额 > 15%（partial）。

### 2.4 确定性等级（A/B/C）

| 条件 | A 级 | B 级 |
|---|---|---|
| 可得财年 / 亏损年数 | ≥ 7 年、最近 10 年至多 0 年亏损 | 最近 7 年至多 1 年亏损 |
| 经营现金流 / 归母净利润（近 5 年合计） | ≥ 0.8 | ≥ 0.6 |
| 净有息负债 / EBITDA | < 2.0 | < 3.0 |
| 两条路线分歧 | < 25% | < 40% |
| 近似项影响（可能让价值变低的计入项合计） | < 每股价值 2% | < 每股价值 5% |
| 股息路线另加：近 3 年现金分红 ≤ 近 3 年（经营现金流 − 资本开支） | 必须满足 | 必须满足 |
| **安全边际** | **25%** | **40%** |

其余为 C 级，不给正式结论。等级衡量的是**数据完整度与模型稳定性，不是公司质量**；
窗口数据缺失时该条件判不通过并写明缺哪些年份。

### 2.5 正式结论

设现价 P，基准价值 V_base，悲观价值 V_pess，乐观价值 V_opt，安全边际 M：

- **候选买点**：P ≤ V_base ×（1 − M）且 P ≤ V_pess。
- **回避**：P > V_opt。
- **等待**：A/B 级、complete，但不是候选买点也不是回避。
- **无法判断**：C 级、partial、资料不足、路线不支持、引擎错误。

候选门槛 = min（V_base ×（1 − M）, V_pess）；报告写明起约束条件（安全边际 / 悲观价值）。
「回避」只表示现价高于乐观情景价值，不是对公司的负面判断。

### 2.6 结论账本

正式结论写入 `data/ledger/equity-conclusions.jsonl`（只追加、不改旧记录）。同一标的/同一分析日/
同一快照重复运行内容一致则跳过、不同则冲突退出。已给正式结论的标的，若新一次评估变为无法判断，
追加一条 `record_type=reversal` 的改判记录（旧记录不改）；从未有正式结论的标的不写无法判断。
校验：`.venv/bin/python -m engine.cli --check-conclusions`。

**可复算**：新写入的正式结论（个股与银行）记录带追溯字段——政策文件 sha256、所用财务快照
（批量快照 id + manifest 哈希，或单标的快照 id + sha256，或银行估值输入哈希）、行情快照
（id、路径、sha256、价格日期）。`./ask --recompute <record_id>` 按记录引用的快照与政策重算并
逐项对比（价格、价格日期、三档价值、等级、安全边际、结论、起约束条件；相对差 ≤ 1e-9），
只读、不改账本。旧记录不改；无法复算的旧记录清单见《维护说明》§7。

## 3. 三池规则（决策③，已批准 2026-11-13）

三池都只回答「过去十年用公开数据看是不是符合规则」；**入池 ≠ 买入**，规则每年复盘
（下次 2027-11-13），不因入池数量调阈值。

### 3.1 好公司池 v1.2（`quality-pool-v1.2`）

范围：沪深 A 股（主板/创业板/科创板），剔除 ST 与金融业；评价窗口最近 10 个完整财年
（不足 10 年用全部可得年份，完整年报少于 7 年剔除）。

| 组 | 条件与阈值 |
|---|---|
| 会赚钱 | 窗口内 ROE 平均 ≥ 15%；ROE ≥ 10% 的年份占比 ≥ 80%；最近 3 年 ROE 平均 ≥ 12% |
| 赚真钱 | 最近 5 年经营现金流合计 ÷ 归母净利润合计 ≥ 0.8；最近 5 年（经营现金流 − 资本开支）合计 > 0 |
| 经得起风浪 | 窗口内亏损年数 = 0；最新财年净有息负债 ÷ EBITDA < 2 |
| 做好人 | 最近 5 年审计意见均为标准无保留；最近 5 年无证监会立案调查、信息披露类行政处罚或公开谴责；控股股东最新质押比例 ≤ 50%；最近 5 年现金分红率 ≥ 20% |

治理三项只对财务条件全过的候选逐家查；取不到记待定，不推断、不用替代口径。

### 3.2 稳定收息池 v1（`income-pool-v1`）

范围与窗口同上。

| 组 | 条件与阈值 |
|---|---|
| 利润稳 | 窗口内亏损年数 = 0；ROE 平均 ≥ 8%；窗口内最低一年 ROE ≥ 5%；归母净利润同比下降 > 30% 的年数 ≤ 1 |
| 分红稳 | 窗口内每个财年都有现金分红；最近 5 年现金分红率 ≥ 40% |
| 分红有现金撑着 | 最近 5 年（经营现金流 − 资本开支）合计 ÷ 现金分红合计 ≥ 1.0；最新财年净有息负债 ÷ EBITDA < 4 |
| 做好人 | 同好公司池：审计、处罚、质押三项 |

收息池与好公司池是两类，不是高低之分；同一家公司可以同时属于两类。所有制只用于展示。

### 3.3 银行池 v1（`bank-pool-v1`）

范围：沪深 A 股上市银行（42 家），完整年报 ≥ 7 年、剔除 ST 后 36 家进入评价；券商、保险不做。

| 组 | 条件与阈值 |
|---|---|
| 会赚钱 | 窗口内亏损年数 = 0；ROE 平均 ≥ 10%；最近 3 年 ROE 平均 ≥ 9%（加权 ROE，年报口径） |
| 资产干净 | 最新不良率 ≤ 1.5%；不良率 5 年变化 ≤ +0.3pp；最新拨备覆盖率 ≥ 200% |
| 资本厚 | 最新核心一级资本充足率 ≥ 9.0% |
| 分红 | 窗口内每个财年都有现金分红；最近 5 年现金分红率 ≥ 25% |
| 做好人 | 审计、处罚（只计证监会口径信息披露类）、控股股东质押 ≤ 50% 三项 |

当前入池 11 家。非银行池银行只给三档价值与「无法判断」，并逐条列出未通过的银行池条件
（条件、实际值、门槛、状态）。

### 3.7 财报季自动更新（决策⑤，2026-11-17）

- 在 5 月 5 日、9 月 5 日、11 月 5 日之后的首次每日更新中，按报告期批量抓取新财报
  （上年年报 / 当年半年报 / 当年三季报），生成新的批量财务快照；旧快照保留。
- 之后个股与银行估值改用新快照（追溯字段随之变化）；单个公司缺新报表时沿用旧数据，
  卡片注明「财报未更新」。
- 银行专用估值 v2.1 的 ROE / 不良率 / 拨备是年度指标：**年报季（5/5）同时刷新银行估值输入**；
  半年报与三季报只更新个股收入表，银行输入的年度指标保持不变（避免把季度数当年度用）。
- 已有正式结论的公司若结论改变（含改判为无法判断），按既有改判规则追加记录；结论不变不写。
- 报告期与档期：`5/5 → 上年 12-31 年报`、`9/5 → 当年 06-30 半年报`、`11/5 → 当年 09-30 三季报`。

### 3.8 行情价格日期与过期提示（补丁，不改任何规则）

- 价格日期按腾讯行情返回的时间戳逐行判断，不用系统时间硬套：行情日早于今天时「当前价」
  就是该行情日收盘价；行情日等于今天且未到 15:00 取昨收；15:00 后取当日收盘。
- 应取日期：交易日 15:00 后为今天，否则为今天之前的上一个交易日；非交易日为最近交易日。
- 最新行情早于应取日期时，`./ask` 带价格的回答第一行与页面顶部提示
  「价格停在 X，已落后 N 个交易日，请运行 ./update 或检查定时任务」；N 只数交易日。
- 提示只影响展示，不改价格、估值、结论或账本记录；补数仍由 `./update` 完成。

## 4. 银行专用估值 v2.1（决策④，已批准 2026-11-14）

### 4.1 方法

合理市净率法（剩余收益法的稳态形式）：

```
每股价值 = 最新每股净资产 × (ROE − g) ÷ (k − g)
```

- 每股净资产（普通股口径）=（最新报告期归母净资产 − 其他权益工具）÷ 总股本。
  只算普通股，避免把优先股/永续债持有人权益算给普通股股东；卡片市净率 = 价格 ÷ 该每股净资产。
- k（银行股权成本）= 个股政策股权成本 + 银行溢价 2.0pp；当前 = 2.7629% + 5.14% + 2.0% = **9.9029%**。
- g：基准 2.0%、悲观 1.5%、乐观 2.5%，且不超过规范化无风险利率。
- 三档普通股 ROE：
  - 基准 = min（最新财年 ROE，近 3 年平均，近 5 年平均）——不假设盈利能力回升。
  - 悲观 = min（近 5 年最低 ROE − 1pp，最新财年 ROE − 3 × 近 3 年年均下滑幅度）；
    若最近未下滑，后一项不适用。
  - 乐观 = 近 3 年平均 ROE。
  - 若拨备覆盖率 < 200% 或不良率 5 年上升 > 0.3pp，三档 ROE 再各减 1pp（资产质量扣减）。
- 安全边际 30%；候选门槛 = min（基准价值 ×（1 − 30%）, 悲观价值）。
- 结论：现价 ≤ 门槛且 ≤ 悲观价值 → 候选买点；现价 > 乐观价值 → 回避；其余 → 等待。
  资格：必须在银行池、数据完整、最近 7 年无亏损、三档价值均为正、有现价；否则「无法判断」。
- 隐含长期回报率 = g +（最新财年 ROE − g）÷ 现价市净率，g = 2%；描述性，不参与结论。
- 历史位置：东方财富市场市净率与分红数据，近 10 年月末序列分位；只作描述，不给买点。
  市场市净率与卡片普通股口径可能略有差异，未做换算（卡片已如实注明）。

### 4.2 覆盖范围

只有银行池 11 家给候选买点/等待/回避；非银行池银行只给三档价值（v2.1 试算）与「无法判断」，
并列出未通过的银行池条件。银行不做 FCFF/普通股息路线估值。

## 7. 已知局限与未做事项

1. **ETF 执行检查未做**：ETF 只做产品资料检查（费率、跟踪标的、缺失项）与跟踪指数的研究信号；
   不制定溢价/流动性/费率买卖门槛，不做执行层面的交易判断，也不给买卖结论。
2. **券商、保险不做**：没有对应的专用估值方法，结论为「无法判断：路线不支持」。
3. **创业板指已移出**：2026-11-13 股东决定移出（官方历史估值不可得，无法做分位与信号）。
   名称仍可识别但返回范围外；已有序列、快照与官方估值账本记录保留不改；跟踪它的 159915 同步移出。
4. **个股政策**：同一股权成本适用所有公司，不区分风险高低；ERP 与规范化人民币利率的搭配口径
   尚无定论；只能前向验证，不能历史回测。v1.1 未经独立 AI 定向复核（股东决定跳过，额度原因），
   以结论账本 + 6 个月复盘补救（首次 2027-05-31）。
5. **三池规则**：三套标准未经独立 AI 审查（额度原因），补救为入池账本每年复盘（2027-11-13）；
   治理数据取不到时记待定，不推断；入池不代表现在便宜。
6. **银行估值 v2.1**：设计方自审、未经独立 AI 审查；ROE 仍在逐年下滑；报表不良率与拨备可能低估
   真实坏账；行业溢价 2.0pp 是政策选择；无法历史回测，只能前向验证（复核 2027-05-31）。
7. **指数**：只做位置描述与研究信号记录，不给买点/目标点位；第三方月度参考与官方周度 PE
   来源、时点、加权口径不同，不能直接对比；恒生科技没有官方历史估值，只做月度快照。
8. **系统整体**：所有结论都依赖固定快照与已批准政策；不预测股价、不给目标价、不给仓位建议。

   不代表公司质量差。护城河是否存在系统无法验证（卡片已固定提示，需股东自行研究）。
