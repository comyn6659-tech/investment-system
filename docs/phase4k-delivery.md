## 6. 对话入口 `ask`

命令：`./ask "<中文问题>"`；`--detail` 展开；`--json` 结构化；`--no-update` 离线。

- 规则化意图识别，不调用大模型：6 位代码 → 常用简称 → 指数/ETF 全名 → 全市场 A 股名称；
  同码/同名的歧义列候选，不猜。
- 支持意图：单只个股、银行、指数、ETF、池名单、是否在池、排行、历史、状态、范围外/歧义。
- 个股可问全部 A 股：用第十批批量输入 + 当日行情重算；不在三池中的公司注明「不在任何池中」。
- 卡片固定结构（默认 ≤25 行）：结论与一句话原因 → 关键数字（现价/日期、候选门槛、距门槛、
  三档价值及用途）→ 为什么（起约束、中文未满足条件）→ 它是什么（池、所有制、周期属性、等级含义）
  → 局限 → 来源与日期、政策版本 → 末行「不构成投资建议」。
- 正式结论按现有规则写入 `data/ledger/equity-conclusions.jsonl`（只追加、冲突不覆盖）；
  无法判断仅在「改判」时追加（见 §7.1）。
- 使用说明：`SKILL.md`。

## 10. 限制

- 指数分位来自第三方供应商历史序列，官方最新值不参与历史排名；不构成买卖信号。
- 银行估值未启用；银行卡片只列公开报表指标，PB 在缺少归母净资产时用
  「2025 归母净利润 ÷ 加权 ROE」推算并在详情注明。
- 官方指数历史在运行日尚未包含 2026-11-12/11-13，候选 A 周度信号停留在 2026-W45；
  这是数据可得时点限制，不是跳过记录。
- 对话入口是规则化识别，不处理任意自然语言；识别不了会列出支持的问法。
